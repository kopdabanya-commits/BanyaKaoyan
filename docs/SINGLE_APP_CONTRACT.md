# 单一 PWA 与双科数据契约

板牙考研只有同一套 PWA 代码、一个原有 Worker 和一个仓库。ECS 提供同版本备用 HTTPS 入口，以供原 workers.dev 在手机网络不可达时使用；它不是另一个学习产品。英语二与政治共享界面与导航，但各自的计划、打卡、错题、笔记、进度、同步快照与备份必须独立。保留原本地存储键及备份格式，不可让一个科目的导入、同步或计划更新覆盖另一个科目。

Worker 与 ECS 是不同浏览器 origin，手机上的存储和安装身份不会自动共享。转移时只能在用户主动操作后按精确 HTTPS origin 复制已验证的本机记录；新入口已有数据就拒绝自动覆盖，旧入口记录始终保留。

公开计划是预设日程，不是用户真实完成记录。私人学习状态只保存在设备和授权的服务器私有数据库。更新或恢复前分别备份两科；冲突时停止自动覆写并让用户选择。不得把私人学习反馈写进 GitHub 文档、测试夹具或日志。
