# 板牙考研 M4｜考研学生使用流程与验收

2026-10-16。用户反馈：文本堆砌、统计不实用、功能层级混乱、英语与政治不统一、Bug多。软件服务于刷题和打卡，不是展示说明文档。

## 信息架构（英语与政治完全共用）
- 底部仅四个入口：今日、日历、进度、设置；顶部一个英语/政治切换器。两科用同一布局，仅内容和强调色不同。
- 今日：日期、简短完成数、紧凑任务卡和打卡操作；任务名称最多两行、类型及预计时间一行；详细说明、错题、笔记在点开后显示。短倒计时标签，无大Banner、重复进度卡、技术状态、长期说明文字。
- 日历：整月日历，点击一天打开独立详情，返回回到原日历；移除三阶段大段说明。前后日期支持点击和原有触屏滑动。
- 进度：最近7天真实打卡数、有打卡的天数、每日完成/已计划的比例、截至今天各类任务完成数；英语可查看登记过错题的最近任务；政治马原肖1000题手工登记数（不自动读取苍盾）。不拿尚未到来的未来任务计算虚假的总体完成率，不推断分数，不把预计分钟当真实计时。
- 设置：备份恢复、同步/更新、学习偏好。云同步保留在设置而非霸占今日首页；两科外观样式一致，数据键各自独立。

## 工程边界和数据保护
- 新增 study-ui.js 纯渲染组件，共享日期、任务和统计结构，app.js 与 politics-ui.js 调用同一组件。
- 不修改任何英语或政治计划、旧任务ID、已有勾选或笔记，不修改学习记录或备份键、不更改华为云接口密钥、原Worker站点或PWA安装身份。
- 新文件加入单一 index.html、SW离线资产列表和Cloudflare安全白名单；缓存版本更新但不使用skipWaiting强制立即替换旧Tab。
- 今日用户说已完成所有打卡，不等于可以由GitHub替其写学习状态。统计读取设备真正保存的打卡和错题，跨科互不影响。

## 可验收标准
1. 英语、政治的今日和任务卡视觉结构一致，页面不再长段铺排，勾选、查看任务说明和保存记录均能操作。
2. 切科、切天、退出重开保留两科独立打卡；日历点击进详情，手机返回日历；底栏今日回真正当天。
3. 近七天统计不计未来日，不输出预测得分、虚构学习时长；马原数字只代表用户登记的马原题库进度。
4. 政治备份、英语计划更新预览、离线缓存、云记录保护以及双科整套自动化回归通过。
5. GitHub CI、Cloudflare生产发布与安卓Edge真机效果分别记录；自动测试成功不等于手机已验收。

## 本轮不做
不开发番茄钟、在线AI自动推断学习成绩、第二个App、政治苍盾自动爬取或增加需反复填写的复盘表。
