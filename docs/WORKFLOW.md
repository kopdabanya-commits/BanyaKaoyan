# 公开仓库开发流程

1. 核对最新 main、开放 PR 和共享文件占用；不得在过期分支覆盖别人的修改。
2. 保持一个 PWA、原 Worker/manifest 身份、英语二与政治独立记录和备份。未经用户要求不更改两科复习计划。
3. 每次提交运行 `node scripts/privacy-check.mjs`、计划/前端测试及后端相关测试。提交前确认没有凭据、原始学习记录、个人备份或服务器私有日志。
4. CI 通过后才合并；发布只用原 Worker。Cloudflare 成功和设备真机验收分别记录。
5. 涉及存储或同步时先提供可恢复备份，拒绝静默覆盖；不能从公开计划或历史文档推断实际进度。
