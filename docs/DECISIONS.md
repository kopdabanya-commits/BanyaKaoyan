# 公开架构决定

1. 板牙考研只有一个 PWA、一个仓库、一个 Cloudflare Worker；英语二与政治共享外壳，但计划、打卡、错题、笔记、进度及备份独立。
2. 继续使用原 Worker 地址、manifest 安装身份和历史本地存储键，避免旧设备记录失联。
3. 计划文件是公开的预设日程，不代表用户实际做题或完成情况。个人记录仅保存在设备或经授权的私有同步数据库。
4. 云同步默认由用户控制；首次同步或恢复前分别备份两科，冲突时不得静默覆盖。
5. 本仓库公开。禁止提交个人学习记录、原始反馈、凭据和服务器私有日志；旧文档中的私人内容不得从 Git 历史重新引入。
6. CI、Cloudflare 发布和手机实际验收分别记录，不能互相替代。
