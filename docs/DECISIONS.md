# 板牙考研｜长期决策与取代关系

> 只记录影响后续开发的长期决定。任何后续明确变更都要写日期、理由和对旧方案的替代关系。发生冲突以用户最新明确决定优先。

## D01：项目与角色
2026-10-15：沿用私有 GitHub 仓库 `kopdabanya-commits/English-II-Plan` 和现有 Cloudflare Worker `english-ii-plan`；不重新创建仓库或Cloudflare项目。ChatGPT负责需求梳理、学习策略和验收；Codex负责主要编码/自动测试；Work仅在可实际接入网页和授权时协助部署与浏览器测试；GitHub保存代码、决策和跨会话状态。不要假设不同AI聊天之间有实时共享电脑或自动指令传递。

## D02：免费与公开站点优先于Access绑卡
2026-10-15：用户明确拒绝绑卡及付费。早期“必须先用Cloudflare Access保护全流量，才能启用网址”的方案 **已被后续决定取代**。用户已手动启用 `workers.dev` 并确认网页能看到；实际站点当前不要求Access登录。
- 网站内容/预设学习计划可公开读取；GitHub仓库仍然Private。
- 本机打卡/错题/笔记不上传，绝不能把个人信息、邮箱、token、凭证写入前端或部署静态资源。
- 旧 `docs/ACCESS_AUTOMATION.md` 和 `configure-access.yml` 仅为历史试验资料，不再主动启动；若用户日后要求私人站点，重新评估免绑卡的服务器端认证方案，不强行恢复旧Access流程。

## D03：设备与操作体验
2026-10-15：主要设备为荣耀 Android 16，使用 Edge 安装 PWA，桌面入口问题已经用户处理好。用户零编程基础、时间紧；优先由AI直接使用已授权GitHub操作，只让用户执行必要的手机验收与系统授权。不要求手动复制大段代码、反复切换账号或重新安装App。

## D04：英语学习目标与数据可信度
2026-10-15：2027考研英语二目标80分，75分是努力争取的基础目标；65天计划 10/15—12/18，按用户计划12/19考试。题型优先级：**作文 ＞ 翻译/新题型 ＞ 完形 ＞ 阅读手感保持**。旧卷阅读约37/40是估计，不可写成2024—2026真实模拟分。新题型2012年是错0题（全对），不得误记。计划日期到来不等于完成。

## D05：专项60—80分钟，单词不进入打卡列表
2026-10-15：用户明确指出“今天只练作文练习量少”，要求当天作文+新题型，并决定**每天其他专项任务合计约60—80分钟，单词时间不用写在任务里**。M2.3将10/15设为作文30 + 新题型30 + 回忆5 = 65分钟；将原定10/17的2014新题型提前，原位置改为复盘，不双刷。一般单词仍自行另学约30—40分钟；内部预算保留单词时间但界面不显示日常单词打卡。

## D06：本地记录不丢、计划可安全更新
应用 localStorage保存记录；不存在服务器数据库或自动云同步。`plan.json` 是唯一权威计划，`plan-data.js` 是同步离线初始快照。每次内容调整同步两者，递增 `meta.revision`，改变 `meta.planVersion`，填写 `meta.changeSummary`。稳定任务ID尽量不变；实际改期保留已有ID，新增不同任务使用新ID；不自动完成任务，不覆盖错题/笔记/历史打卡。更新前后须能导出和恢复。

## D07：后期真题保留、不可自动补债
2024卷暂定11/21—11/24，2025卷12/5—12/8，2026卷12/12—12/15作弹性模拟，避免无证据提前使用或标完成。临时没学的任务不自动累积次日双倍，优先对剩余日程做减法和重排。未确认连续3小时条件时不要硬塞整卷到某日。

## D08：验证必须分层
GitHub改动/自动测试通过 ≠ Cloudflare部署成功 ≠ 用户手机真实验收通过。每层单独记录证据；不得宣称“已自动同步”或“全部稳定”而无法验证。保持 `workers_dev=true` / `preview_urls=false`，只在用户新指令明确改变访问方案时调整。

## D09：以后有冲突时的信息优先级
最新用户明确要求 > 用户真实学习反馈或其主动导出的本机记录 > 当前GitHub main代码与 `plan.json` > `PROJECT_STATUS.md` 最近确认的部署状态 > 历史基线 > 旧聊天或过时文档。历史文档必须保留时间标签，不能作为最新状态覆盖新决策。


## D10：考研学生专注型UI（2026-10-15）
用户要求优化动效、交互逻辑和文字介绍，使研途英语二更适合考研学生。采用**任务优先、操作少、文案具体、反馈准确、动效克制**的原则：今日训练一眼看懂、点击任务先看做题方法、错题/一句话复盘后可直接完成；高级改期/改名称收纳，避免占据主流程。动画短而轻，支持系统“减少动态效果”，避免游戏化奖励/虚构学习成绩。保持用户单词另计、专项60—80分钟、免费免绑卡、原有打卡与笔记存储不变。


## D11：视觉升级、政治准备与番茄 Todo 分工（2026-10-15）
用户要求升级UI动效和视觉质量，并增加智能化、丰富且真正能用的功能；打算后续增加考研政治计划，希望项目提前留好扩展接口。**明确不做计时功能**，已有番茄 Todo 负责专注与时间管理。M2.5提供双科目入口（英语正常、政治待建档）、可解释的本地规则建议、实际打卡七日统计和深浅视觉主题。政治不能在没有真实学习基线时编造训练量或成绩；未来用独立计划/存储/备份机制接入，不破坏英语数据。不得将本机规则建议称为在线AI已自动规划。


## D12：每天保持客观题题感；允许英语专项适度延长（2026-10-15，覆盖原D05时长上限）
用户最新明确要求“无论当天做什么，都必须至少练一篇阅读、一次新题型或一套完形”，不接受仅作文或翻译的一整天；时间可以稍微延长。还要求尽量综合小红书/抖音/B站个人博主和高校真实学生经验，不照搬机构广告或高强度课表。
M2.6保留所有M2.3原99项任务，另外对42天缺乏客观题练习的日子新增22项阅读、10项新题型和10项完形，合计141项。原有已经包含客观题的日子、2024—2026年模考含客观题的分段都不加题；最多90分钟专项，主要新增日为85—90分钟，单词另计。总预算建议130分钟（含自学单词），用户手动确认新版后方可上调旧预算，并保留手机所有学习记录。不自动双倍补课。**本决策取代D05“每天专项60—80分钟”的硬上限**，但保留单词不显示在打卡列表的长期决定。资料详见`DAILY_QUESTION_FEEL_2026-10-15.md`。


## D13：正式启用政治、继续使用苍盾（2026-10-15）
用户要求在研途正式加入2027考研政治复习计划，上海地区目标60—65。当前徐涛27强化课第6集对立统一规律；苍盾考研微信小程序肖1000题截图马原93/396，暂无纸质教材。不能从93/396推断整门政治进度，也不能从正确率推断最终成绩。
- 英语最新M2.6专项上限90分钟的决定继续有效；政治另按政治模块单独安排。10月后半月60—75分钟政治/天，11月70—100，12月肖四阶段90—120；数学和专业课冲突时允许缩减政治，不自动补双倍任务。
- 肖八肖四按正式发布和实际取得后启用；未取得使用已有1000题和官方时政，不硬性购买全套纸质资料。
- 苍盾与研途没有自动互通接口，研途仅管理任务和用户手动反馈，不能索取苍盾账号密码、隐藏读取外部App、宣传实时同步；任何疑似登录名不写入静态资源。
- 政治独立状态、独立计划、独立导出恢复；不触碰英语记录。本机静态逻辑不是云端AI监控，继续不增加番茄钟。


## D14：正式命名“板牙考研”，一个App而不是两个App（2026-10-15，最高优先级）
用户明确不喜欢“研途”，将App正式更名为「板牙考研」。英语二、政治**属于同一个软件本体，两个不同科目和两套独立学习计划**：共用图标安装身份、界面/底部导航、设置、静态部署和科目切换；但两科任务、成绩、打卡、错题、复盘、数据版本和备份应隔离，修改其一不影响另一科。用户明确指出此前“两个App合并”的理解错误，**不要将未来工作拆成独立英语App和政治App或两个站点**。

命名仅修改用户可见的App标题、PWA manifest、设置说明、备份下载文件名、项目指令；保留原 `kopdabanya-commits/English-II-Plan` 仓库、Worker `english-ii-plan`、workers.dev站点和历史本机存储键/备份内部格式，以保护已安装Edge PWA和旧记录。当前政治已经在同一仓库的M2.7 PR #7 合并，绝不按旧“政治待建档”说明覆盖实际代码。继续不加入计时器，用户用番茄Todo。

## D15：两个开发聊天共用一套工作流，防止后提交覆盖先开发（2026-10-15）
英语和政治的工作可以由不同对话并行**在同一GitHub仓库**开发，但不是独立App；新会话必须读取最新main、`docs/ACTIVE_WORK.md`、开放PR、`docs/SINGLE_APP_CONTRACT.md`后才修改。独立计划文件由各科负责，共享 `app.js`、`styles.css`、`index.html`、`sw.js`、manifest等需要一个集成PR串行合并。禁止不对齐main的旧分支盲合并；所有PR跑两科回归、跨科隔离测试才准合并；每次提交回写状态，明确区分代码/CI/Cloudflare/荣耀Edge真机四类证据。历史仓库命名不是“只许英语”。


## D16：复用华为云单ECS做独立双科云同步；默认本地优先（2026-10-16）
用户明确授权继续完成同一「板牙考研」PWA的技术开发、华为云Ubuntu约2GB ECS云记录同步部署，不再运行旧图书馆服务；不购买新高配ECS、不建第二套PWA/Cloudflare Worker、不改历史浏览器存储键。现有PWA联网备份与同步必须各科独立、离线可用、第一次云写入/恢复人工确认、409与本地并发变化不自动覆盖。
