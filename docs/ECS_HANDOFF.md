# 华为云 ECS 公开技术交接

板牙考研在原 ECS 上运行一个双科独立同步后端，公网 API 使用 HTTPS；后端仅在服务器环回地址监听。服务器登录凭据、同步令牌及其原始值不在仓库中，分别由 GitHub Actions Secret 和服务器私有配置管理。

当前云执行器可能无法直接连接服务器。运维前先核对最新 GitHub Actions 工作流、SSH 固定主机公钥及服务器实际状态；连接失败不能推断为密码错误。不要将任何凭据、原始学习数据、详细服务器清单或日志写入公开仓库/Actions 输出。

公开网站和代码的可用性不等于用户手机已经完成云同步。首次同步、恢复或冲突处理前必须分别保护英语二和政治的原始数据，且由用户在设备端确认。证书实际续期、数据库备份与生产 API 状态应实时复核。
