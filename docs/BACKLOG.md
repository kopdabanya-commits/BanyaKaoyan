# 尚待完成或单独验收

本清单不存放个人学习记录；每次接手前核对最新 main、Actions 和线上状态。

1. **手机真实验收：** 在原 PWA 中核对 M4.1 界面、两科旧记录、分别导出备份、离线启动与重新打开后的数据。自动化和网页 200 不能替代设备验收。
2. **云同步真实验收：** 由用户在手机端分别确认首次同步，验证上传/下载、双科隔离、断网恢复、409 冲突和恢复前备份；不要从聊天或公开仓库导入私人记录。
3. **服务器长期运维：** 定期核对 IP HTTPS 证书实际自动续期、数据库备份生成和恢复演练、后端健康及授权访问；详细原始日志保持私有。
4. **公开仓库隐私：** 当前文档已去除具体个人近况，CI 拦截常见凭据/备份；Git 历史、旧分支和现有公开计划仍可见。用户选择暂不修改计划文件。若以后需要真正限制访问，应评估改回私有仓库及 Actions 配额；单靠不在 README 放链接无法隐藏公开仓库。
5. **访问体验与可选域名：** 若原 Workers 网址在用户网络环境中不稳定，先测试 DNS/HTTPS 与迁移方案；新增费用或改入口必须由用户决定，不能静默丢失旧 origin 的本机数据。
6. **对话直读私人记录：** 当前服务器只提供需 Bearer 密钥的双科快照接口，普通 GPT 对话没有该授权，也不能自动读取。后续需设计只读、按科目和时间范围授权、可撤销、无聊天明文密钥的连接；先完成手机端的云同步验收，再在受控环境验证读取。不得将快照发布到公开仓库或公开网址。
7. **无 VPN 手机访问：** 用户手机已确认不用 VPN 可访问 ECS HTTPS `/health`，原 workers.dev 无法打开。M4.3 准备由同一 ECS IP 提供同版本备用入口，原 Worker 继续运行；正式发布后仍须手机验证备用 PWA、两科数据一次性复制与离线启动。浏览器把两个网址视为不同 origin 和安装入口，不能静默迁移或自动改写旧桌面图标。

常规计划修改按 [WORKFLOW.md](WORKFLOW.md) 的短流程单独处理，不把以上所有事项强行塞进一次对话或 PR。
