# 研途英语二｜用户与AI的日常操作手册

## 用户每天怎么用（手机Edge）
打开桌面“研途英语二” → 查看今天的 **每天一项阅读／新题型／完形题感训练加当天原任务的专项计划** → 逐项练习 → 勾选完成 → 任务详情中填写错题数/复盘笔记。单词请按个人习惯单独学习，不用在App里打卡。系统保存的是你实际提交的记录，不会因日期变化自动当成完成。

## 用户如何让我改后面的安排
告诉ChatGPT你练了哪年哪种题、错了几道、作文是否写得出来、最近每天能花多少时间；或在App `设置 → 复制学习近况`，直接粘贴给ChatGPT。AI据此修改GitHub里的未来安排；**不能自动从你的手机读取这些记录**。

## 计划发布后怎么更新
1. 确认AI已提交至 `main`，Cloudflare构建/发布需要一些时间。
2. 退出并重新打开Edge桌面App → `设置 → 检查计划更新`。
3. 弹出新版预览时，核对变更，点击 `保留记录并应用`。
4. 如果没出现新版本，不要清理网站数据或卸载；让AI查部署，再稍后检查。
5. 若静态资源代码更新，可能要关闭所有旧浏览器标签和PWA重启才能切换；计划内容更新与App程序缓存更新是两回事。

## 防止学习记录丢失
- App记录在当前网站来源的localStorage。不是存在GitHub，也不因同一GitHub账号登录就多端同步。
- 建议每周至少一次或重要更新前后在 `设置 → 导出学习记录` 保存JSON文件（包含你自己的笔记，妥善保管）。
- 更换浏览器、换机、清除站点数据或卸载前必须先备份。Edge和Chrome一般不共享这一份网站存储。
- 恢复时 `设置 → 导入备份`，先核对备份是否正确；恢复前应用会尝试保存恢复前副本。发现问题先导出当前数据再排查，不盲目覆盖。
- 不要把带个人笔记的备份文件提交到GitHub或公开给他人。

## Edge安装或图标找不到
用户曾通过微软Edge安装后找不到桌面入口，已自行解决。再次发生时，先检查 Edge 的 `创建桌面快捷方式` 权限、应用列表和系统桌面显示设置；不要立刻要求卸载或删除浏览器数据。未实机验证的荣耀菜单路径，以手机实际界面为准。

## 目前网站的隐私边界
Github仓库是Private；网站 `workers.dev` 当前不设置Access登录限制，**别人可能访问预设计划和网页程序**。但学习打卡/笔记存在用户本机，不自动上云。不要在公开计划里录入真实姓名、邮箱、准考证、账户密码等。

## 面向工程接手者的检查顺序
先跑 `node --check app.js`、`node --check planner-core.js`、`node --check plan-data.js`、`node --check sw.js`、`node scripts/check.mjs`、`node --test scripts/test.mjs scripts/sw-test.mjs scripts/access-test.mjs`。再看PR的 `Validate planner`；最后检查Cloudflare对应提交的生产部署和真实Edge体验。CI不能代替手机安装、离线和存储测试。

## 如何记录“验收”
用户“看到网站”只能证明当时网站可打开；“在Edge安装好了”不能证明之后每次离线更新都正常。将本次确实检查的步骤、结果、日期更新到 `PROJECT_STATUS.md`。别把GitHub main推送当成手机已经运行新版的证据。

## M2.6更新后的日常训练
- 每天至少含一项客观题练手。普通新增日为限时练20—25分钟，旧作文/翻译任务仍保留，多数新增日总专项85—90分钟；单词另行安排。
- 计划更新到`2026.10.15-m2.6`时，在“设置→检查计划更新”先预览，再选择“保留记录并应用”。旧默认总预算不足130分钟会同步上调到130（含单词），个人打卡/错题/笔记/改期都应保留。先导出备份更稳妥。
- 新卷2024—2026保留给原来的分段模考，不用额外拿新卷做每日题感。
