# 板牙考研｜一个手机App的使用、更新和备份手册

适用：荣耀Android16、微软Edge安装的PWA。「板牙考研」只有一个安装入口、一个网址和一套导航，内含英语二、政治两科。正式界面名更新不需要更换现有域名，不要为改名重新建站/清数据。

## 每天如何使用
- 进入现有桌面PWA，顶部点击「英语二」或「政治」。两科共用底部「今日／日历／进度／设置」，切换只是切换学科页面。
- 英语二：每天至少一篇阅读、一组新题型或一套完形，和当天作文/翻译等任务一起做；单词在其他软件自行背，不在App打卡。任务详情可记录错题和一句话复盘。
- 政治：根据徐涛课与苍盾肖1000题对应章节学习，再在板牙考研**手动**打卡、录入错题和马原已做题数。苍盾小程序和本App之间没有自动同步；任务日期到来不等于实际做完。
- 英语二和政治的预计任务分钟数分别统计，不内置计时器，也不获取番茄 Todo 数据。
- App会记住上次查看的科目，但这只是一条界面偏好记录，不会改变另外一科的任务或笔记。

## 必须理解的两个“更新”
- **应用程序更新：** 修改了界面、manifest、政治静态脚本等，随Cloudflare Worker资源构建上线；关闭Edge旧页面/PWA再打开，必要时「设置→检查应用更新」以等待新SW安装生效。Android桌面显示的安装名称是否自动随manifest变化由浏览器/系统决定；不要因为旧桌面标签仍在而直接删除数据。
- **英语学习计划更新：** 英语二科目「设置→检查计划更新」，由 `plan.json` 拉取新日程，先预览变化，再由你点击「保留记录并应用」。这里的确认不代表政治计划已联机更新。
- **政治学习计划更新：** 目前政治从PWA的 `politics-plan-data.js` 离线镜像加载，现阶段尚无和英语完全相同的联机预览/迁移控件。政治后续计划改动由开发者按单科独立版本、稳定任务ID和兼容性测试处理，用户等相应程序更新后验证自己的政治数据仍在。

## 保护真实学习记录（改名尤其重要）
- 本机存储同一个网站的三个不同信息区：英语旧键 `yantu_english_2026_m1`、政治旧键 `yantu_politics_2026_v1`、UI选中科目键 `banya_active_subject_v1`。内部有旧单词“yantu”是为了兼容，**不代表需要删除数据或另装研途**。
- 每周或重要版本升级前，分别在「英语二→设置→导出学习记录」和「政治→设置→导出政治备份」导出两份JSON，妥善保存。备份含私人学习笔记，不上传公开GitHub。
- 恢复时只用相应科目设置里的导入按钮；英语备份不能导入政治、政治备份不能导入英语。恢复前应用尽量留回退副本，但不能代替用户离线保存的重要备份。
- 不要清除Edge站点数据、换域名、卸载旧PWA来“刷新”程序。如果内容不更新，先核实Worker上线与SW缓存。Edge与Chrome即便访问同一网址，也通常不能直接共享各自localStorage。
- 目前用户记录在本机，没有自动云端跨设备同步、后台通知或实时读取外部小程序。

## 手机上一次最小验收
1. 同一桌面App打开后能显示「板牙考研」并看到英语二/政治两个科目标签；
2. 英语二仍可查看原先打卡/错题，新增或撤销一次测试记录，切政治再回来后英语记录不丢；
3. 政治可打开今天/日历/进度/设置，独立打卡/撤销、手动登记已做题数；切英语后数据不互相覆盖；
4. 分别导出两份备份，关闭App后重开，检查所选科目和两科记录；
5. 若离线启动仍无法正常使用、桌面名称没更新或政治资料与现有苍盾进度不符，把具体现象反馈给AI；**不要先重装或删除数据**。

## 遇到更新失败怎么办
先让开发者检查 `main`提交和PR CI → Cloudflare Worker是否真正部署该版本 → 当前Edge PWA安装缓存状态。保持旧网址和浏览器存储，尽量用导出JSON保护原记录。真实手机验收未完成前不宣称“全部上线正常”。
