# M7.3：受限自主执行（默认关闭）

独立于 M7.2 预览，新增所有者专用 `/v1/ai/auto/` 通道。模型没有执行工具，仍只输出 PlanningSuggestion。原预览提交的 previewOnly 拒绝保留；服务器 AutoService 在预先授权后独立验证并执行。

## 权限与开关

三道门同时满足才可调用：服务器 BANYA_AUTO_ENABLED、已有 AI 配置/预算 ready、本人自动管理总开关及该科授权。初始化不创建已启用开关或授权。GET status 免费，返回总开关、科目授权和最近20次收据，不返回密钥/原快照。

- POST auto/control：版本校验、显式 set_auto_control。
- POST auto/grants/{subject}：独立科目版本、未来最多30天范围、允许字段和题型、是否可新增、单次1–3项、日/周/月次数、月预算、至少6小时冷却、周期检测与额外错题分享同意。启用必须主动确认数据处理和正预算；默认关闭、预算0。
- POST auto/enqueue：本人要求检查一次，只入队、无模型调用。正常同步仅在真实打卡/错题/用时/笔记等字段变化时入队；计划覆盖层、同步元数据或服务器自动写入不产生递归事件。
- POST auto/runs/{id}/undo：本人撤销；只有当前服务器仍是该次应用版本时才允许，先备份再恢复，撤销后暂停该科。已有新手机记录就409，不能强行覆盖；重复撤销返回同一收据。

这些不是模型能力注册表的写工具；受限 GPT Action key 不能调用所有者接口。

## 执行与保护

同一 SQLite 增加 auto_control/auto_permissions/auto_permission_history/auto_events/auto_runs；不改原快照协议。权限修正和自动暂停保留旧版本。生命周期工作器每15秒处理队列，默认不启动；周期检测只有本人另行授权才入队。

先免费 analyze，需要重新规划才进入模型流程；不因页面打开收费。去重、同科冷却/限额、全局 pending 互斥与 M6 共用 ai_requests 的月调用/保守费用预留。费用为上界预留，超时保留；没有重复收费重试。跨月按 UTC，周限额为滚动7日。周期事件每日去重。

模型调用不占数据库事务。模型返回后重新 BEGIN IMMEDIATE，核对总开关/授权版本、档案/快照/模板和有效期，再复用 validate_suggestion/apply_patch；额外检查科目、允许题型/字段、未来日期、数量及新增许可。只改未完成未来任务，不改历史、不做、实际时间、错题、笔记、长期档案或其他科目。

原快照存入 agent_backups 和 history，在同一事务更新覆盖层、版本、审计和收据；失败完整回滚并暂停授权。不传全量快照给模型。手机使用现有冲突/本机备份机制收取；离线新记录不能被静默覆盖。

进程重启将未确认 pending 置为 unknown、保留预算且暂停相关科目，不再次请求模型；单实例 Uvicorn 工作器，不能启动多个独立自动调度进程。模型超时/错误、冲突和数据库异常停止本次并暂停；权限失效不会重放旧请求。

审计保存原因、有限前后对照、来源、请求 ID、受限 token 用量和状态；不保存内部推理、原始提示词或凭据。原数据库在线备份涵盖新增表，升级守卫对其原行逐一核对。

## 验证边界

只用合成双科记录与模拟 provider，测试自主修改、精确事务备份、CAS、撤销/新记录冲突、权限/版本/预算/超时/重启/回滚和去重。未导入本人档案、未创建生产授权、未启用付费或部署。

初始学习背景不写入公开代码或转换为打卡；自动规划始终用服务器最新有效的档案和实际记录。真实 DeepSeek、Android 离线恢复和生产迁移仍需后续授权验收。
