# 重新构思：把 AI 从"另一个界面"变成"计划上的一个动作"

## 为什么现在难用（结构性原因，不是 bug）

1. **入口太深**：改计划要先离开计划页 → 进「学习助手」→ 打开模态 → 勾同意 → 展开范围 → 说 → 等 → 看卡片。改一条任务要跨越三个上下文。
2. **AI 不知道你在看什么**：科目、日期范围都要手动选，它只能看见你选的那一小段；而"明天的翻译"这种话，人默认对方看得见你的今天。
3. **"确认"和"执行"混在一起**：预览卡片既像结果又像按钮，用户不知道现在改了没有。
4. **失败就是死路**：同步失败、版本冲突、服务端拒绝，都会让输入框锁住或让你"去查询"，没有一条是"再试一次"。
5. **自动管理是另一套东西**：后台按同步事件跑，和你说的话无关；用户以为"开了自动就会听话"，实际不会。

## 一句话原则

> **计划本身是界面，AI 只是输入方式。**

用户不该"进入 AI"，而是在计划上直接说一句话，然后**看着计划变**。

## 新形态（4 个屏 + 一个命令栏）

### 1. 今天（默认首页）
- 今天的任务、预计时长、完成/不做
- 底部常驻一行：`改计划…`（可语音输入）
- 一句话 → 计划区直接出现**改动预览（就地高亮）** → 直接生效，底部一条 toast：「已把翻译挪到 10-22 · 撤销」

### 2. 本周 / 日历
- 周视图为主（手机上一屏 7 天），可拖拽改期
- 顶部一条"这周还剩 X 分钟"，超了就标红

### 3. 进展
- 只显示真实记录（沿用现有统计规则）

### 4. 设置
- AI 开关、预算、自动规则——**不再有独立的"学习助手"Tab**

命令栏的行为：
- 不需要选科目/日期：默认用"当前看到的科目 + 当前视图的日期范围"
- 说不清时只问一句，不弹表单
- 结果永远落在计划上，不落在聊天气泡里
- 想深聊时再点开"对话"，对话是次要入口

## 计划怎么推进（替代现在的一次性大计划）

- **每天一个收尾**：晚上固定时间检查当天未完成 → 按规则顺延或略过（规则可一句话设定）
- **每周一次复盘**：生成下周草案 → 你确认 → 生效
- **随时微调**：一句话改，立即生效，可撤销
- 三种动作明确区分：`完成` / `不做` / `顺延`，统计只认前两种

## 保留什么

后端（快照、版本、备份、AI 校验、双科隔离）、安全边界（不写打卡、不覆盖新记录）、PWA 单应用——**全部不动**。改的是入口、布局和交互顺序。

## 分期

- **Phase 1（先解决"一句话"）**：今天页加命令栏；去掉模态与范围选择；就地预览 + 撤销；同步失败不再锁死；同意改为启用 AI 时一次性确认。
- **Phase 2（计划推进）**：日收尾 + 周复盘两个循环。
- **Phase 3（自动规则）**：一句话生成规则，接管日常顺延。
