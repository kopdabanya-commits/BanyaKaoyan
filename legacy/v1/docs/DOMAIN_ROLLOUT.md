# 域名迁移技术约束

原有 Workers 网址继续运行。由于用户手机不用 VPN 可以打开现有华为云 IP 的 HTTPS 健康页，而无法打开 workers.dev，同版本 PWA 增加 ECS IP 备用入口；不购买域名、不新建 Worker 或仓库。若未来添加自有域名，仍须先确认 DNS、HTTPS 和费用，再由用户决定。

浏览器存储按 origin 隔离。ECS 入口不能直接读取旧 Worker 的两科本地记录或同步令牌。用户在旧入口主动启动的同浏览器 HTTPS 页面复制只向固定 ECS origin 发送数据；记录和令牌不进 URL、GitHub 或日志，旧入口记录不删除，新入口已有记录就拒绝覆盖。转移后仍须在手机核对两科与云同步，不能把自动化测试当成设备验收。新 origin 也意味着旧桌面图标不能自动指向新入口。
