# 研途 · 2027 考研英语二复习 PWA

这是个人使用的考研英语二计划管理应用。GitHub 仓库保持 Private；计划代码和学习记录分离。

## 目标与约束
- 2026-12-19 英语二考试；计划从 2026-10-15 到 2026-12-18（65天）。
- 每天英语总计 90～120 分钟，其中背单词 30～40 分钟。
- 阅读近七年一刷约 37/40（回忆估计），阅读二刷到 2011 Text 3；新题型约 6.5/10；完形约 6/10；作文是重点，翻译中文表达待提高。
- 75 分作为努力达到的目标，冲刺 80 分；不保证分数。
- 2024～2026 真题预留三次弹性模拟。

## 架构
离线优先的无框架 HTML/CSS/JS PWA。发布计划保存在 `plan.json`；完成记录/错题笔记保存在当前浏览器本地。云端只更新计划、不上传个人学习记录。每个任务保留稳定 ID，更新计划不能抹除用户打卡。

## 部署
Cloudflare Pages：连接本仓库，在 Pages 中设置框架为 None、构建命令留空、输出目录 `/`；部署为静态网站。仓库私有不等于部署的网站私有，正式使用前需确认是否需要 Cloudflare Access 限制访问。若启用访问控制，需在真机检查 PWA 的离线缓存与更新是否正常。
